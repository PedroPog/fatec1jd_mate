Parte 1: Teoria dos Conjuntos

Aula 01. Como agrupar coisas e fazer contas com esses grupos.

1.1O que é um conjunto

Um conjunto é uma coleção de objetos bem definida. “Bem definida” quer dizer que, para qualquer objeto, dá para responder com certeza: ele está ou não está no conjunto. Cada objeto do conjunto se chama elemento.

Conjunto = coleção bem definida de objetos. Elemento = cada objeto dela.

Conjuntos: letra maiúscula (A, B, X). Elementos: letra minúscula (a, b, x).

Finito: dá para contar até o fim. Infinito: nunca acaba.

Exemplos
  • Dias em que uma pessoa nada: segunda, quarta, sexta. Finito.
  • Vogais: a, e, i, o, u. Finito.
  • Números pares: 0, 2, 4, 6, 8… Infinito.

1.2Como representar um conjunto

Existem três jeitos, e todos descrevem a mesma coisa.

Por enumeração (listando): A = {a, e, i, o, u}

Por propriedade: A = {x | x é vogal}. O símbolo | se lê “tal que”.

Diagrama de Venn: uma “bolha” com os elementos dentro.

Exemplo

O conjunto dos pares maiores que 0 e menores que 15:

Enumeração: A = {2, 4, 6, 8, 10, 12, 14}

Propriedade: A = {x | x é par e 0 < x < 15}, lido como “x tal que x é par, maior que zero e menor que 15”.

1.3Pertinência: ∈ e ∉

Pertinência responde uma pergunta simples: este elemento está dentro deste conjunto?

x ∈ A → x pertence a A

x ∉ A → x não pertence a A

Pertinência sempre liga elemento → conjunto.

Exemplo

A = {a, e, i, o, u}:  a ∈ A,  e ∈ A,  b ∉ A,  w ∉ A

X = {x | x é primo positivo}:  2 ∈ X,  13 ∈ X,  8 ∉ X,  1 ∉ X (1 não é primo).

1.4Conjuntos especiais

Universo (U): o conjunto maior onde tudo que estamos estudando está. Ex.: U = as 26 letras do alfabeto, A = as vogais.

Unitário: tem um único elemento. Ex.: A = {2}

Vazio: não tem nenhum elemento. Escreve-se ∅ ou { }

Exemplo de vazio

A = {x | x é um habitante da Terra com mais de 200 anos} → A = ∅

Pegadinha

{∅} não é vazio. É uma caixa com uma coisa dentro, então é unitário. Para o vazio, escreva ∅ ou { }, nunca os dois juntos.

1.5Conjuntos iguais

A = B quando os dois têm exatamente os mesmos elementos.

A = B ⇔ (∀x | x ∈ A ⇔ x ∈ B)

Leitura: “para todo x, x está em A se e somente se x está em B”.

Exemplos

{1, 2, 3, 4} = {3, 1, 4, 2} → a ordem não importa.

{1, 1, 2} = {1, 2} → repetir não muda nada.

{1, 5, 7, 9, 10} ≠ {1, 5, 7, 8, 10} → o 9 e o 8 são diferentes.

1.6Inclusão: subconjuntos (⊂)

A é subconjunto de B quando todo elemento de A também está em B. Pense em “A cabe inteiro dentro de B”.

A ⊂ B → A está contido em B

B ⊃ A → B contém A

A ⊄ B → A não está contido em B (tem pelo menos um elemento fora)

A ⊂ B ⇔ (∀x | x ∈ A ⇒ x ∈ B)

Sempre vale: ∅ ⊂ A (vazio é subconjunto de todo conjunto) e A ⊂ A.

Exemplos

A = {1, 5}, B = {1, 5, 7, 9, 10} → A ⊂ B

C = {5, 6, 3, 2}, D = {3, 5, 7, 6} → C ⊄ D, porque 2 ∈ C mas 2 ∉ D.

A regra que mais cai em prova

∈ liga elemento com conjunto. ⊂ liga conjunto com conjunto.

Com A = {0, 1}:  1 ∈ A ✔   {1} ⊂ A ✔   1 ⊂ A ✘   {1} ∈ A ✘

1.7Conjunto das partes P(A)

É o conjunto formado por todos os subconjuntos de A, incluindo o vazio e o próprio A.

n(P(A)) = 2n(A)

n(A) = número de elementos de A.

Exemplo

A = {x, y, z}, então n(A) = 3 e n(P(A)) = 2³ = 8:

P(A) = {∅, {x}, {y}, {z}, {x, y}, {x, z}, {y, z}, {x, y, z}}

Por que 2n? Para montar um subconjunto, cada elemento tem 2 opções: entra ou não entra. Com 3 elementos: 2 × 2 × 2 = 8.

1.8Operações com conjuntos

A parte pintada de amarelo em cada diagrama é o resultado da operação.

União: A ∪ B = {x | x ∈ A ou x ∈ B} → junta tudo, sem repetir.

Interseção: A ∩ B = {x | x ∈ A e x ∈ B} → só o que é comum.

Disjuntos: quando A ∩ B = ∅ (nada em comum).

Diferença: A − B = {x | x ∈ A e x ∉ B} → o que só A tem. Em geral A − B ≠ B − A.

Complementar: se B ⊂ A, então ∁AB = A − B. Em relação ao universo: Ā = ∁A = U − A.

Exemplo resolvido

A = pares naturais menores que 10, B = primos menores que 10.

Primeiro liste: A = {0, 2, 4, 6, 8} e B = {2, 3, 5, 7}.

A ∪ B = {0, 2, 3, 4, 5, 6, 7, 8}

A ∩ B = {2}

A − B = {0, 4, 6, 8}

B − A = {3, 5, 7}

Exemplo: complementar

X = {1, 2, 4}, Y = {1, 2, 3, 4, 5}. Como X ⊂ Y: ∁YX = Y − X = {3, 5}

Se A = {x ∈ ℝ | x > 2}, então Ā = {x ∈ ℝ | x ≤ 2}. Repare que o 2 vai para o complementar.

Pegadinha: ∁A ∩ B não é o mesmo que ∁(A ∩ B)

U = {a, b, c, d, e, f, g, h}, A = {a, b, c, d, e}, B = {d, e, f, g}

∁A ∩ B: primeiro ∁A = {f, g, h}, depois ∩ B = {f, g}.

∁(A ∩ B): primeiro A ∩ B = {d, e}, depois o complementar: {a, b, c, f, g, h}.

O parêntese muda tudo: resolva sempre o que está dentro dele primeiro.

1.9Contando elementos (problemas de pesquisa)

Quando você soma n(A) + n(B), quem está nos dois foi contado duas vezes. Por isso se tira a interseção uma vez.

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Só em um dos dois: n(A) + n(B) − 2·n(A ∩ B)

n(A∪B∪C) = n(A) + n(B) + n(C) − n(A∩B) − n(A∩C) − n(B∩C) + n(A∩B∩C)

Método seguro: preencha o diagrama de dentro para fora (comece pela interseção).

Exemplo com 2 conjuntos

Escola com 630 alunos: 250 estudam matemática, 210 física e 90 estudam as duas.

  1. Meio (as duas): 90
  2. Só matemática: 250 − 90 = 160
  3. Só física: 210 − 90 = 120
  4. Matemática ou física: 160 + 90 + 120 = 370 (ou pela fórmula: 250 + 210 − 90 = 370)
  5. Só uma das duas: 160 + 120 = 280
  6. Nenhuma: 630 − 370 = 260

Se o problema der “260 não estudam nenhuma” e pedir a interseção, faz ao contrário: n(A∪B) = 630 − 260 = 370, então 370 = 250 + 210 − x e x = 90.

Exemplo com 3 conjuntos (jornais)

600 leitores. Leem A: 300, B: 220, C: 150. A e B: 100, B e C: 80, A e C: 50. Os três: 20.

  1. Centro (os três): 20
  2. Só A e B: 100 − 20 = 80  |  só B e C: 80 − 20 = 60  |  só A e C: 50 − 20 = 30
  3. Só A: 300 − 80 − 30 − 20 = 170
  4. Só B: 220 − 80 − 60 − 20 = 60
  5. Só C: 150 − 30 − 60 − 20 = 40
  6. Leem algum: 170 + 60 + 40 + 80 + 60 + 30 + 20 = 460. Nenhum: 600 − 460 = 140

Respostas: somente um jornal = 170 + 60 + 40 = 270; somente dois = 80 + 60 + 30 = 170; pelo menos dois = 170 + 20 = 190.

Conferindo pela fórmula: 300 + 220 + 150 − 100 − 80 − 50 + 20 = 460 ✔

Atenção às palavras

“Somente dois” não inclui quem lê os três. “Pelo menos dois” inclui (dois ou mais).

1.10Propriedades e Leis de De Morgan

PropriedadeO que diz
ComutativaA ∪ B = B ∪ A    A ∩ B = B ∩ A
AssociativaA ∪ (B ∪ C) = (A ∪ B) ∪ C
DistributivaA ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
IdempotenteA ∪ A = A    A ∩ A = A
VazioA ∪ ∅ = A    A ∩ ∅ = ∅
UniversoA ∩ U = A
InclusãoA ⊂ B ⇔ A ∪ B = B ⇔ A ∩ B = A

De Morgan: troca ∪ por ∩ (ou ao contrário) e complementa cada um.

(A ∪ B)c = Ac ∩ Bc

(A ∩ B)c = Ac ∪ Bc

Parte 2: Lógica Proposicional

Aula 02. Como decidir se frases são verdadeiras ou falsas quando são combinadas.

2.1Proposição

Uma proposição é uma frase declarativa que é verdadeira (V) ou falsa (F), nunca as duas ao mesmo tempo.

Proposição: frase afirmativa com valor V ou F.

Não é proposição: pergunta, ordem, exclamação, ou frase com variável solta (ex.: “x > 3” sem saber x).

Representamos por letras minúsculas: p, q, r… e escrevemos V(p) = V para “o valor de p é verdadeiro”.

Exemplos

“Brasil é um país” → V  |  “Buenos Aires é a capital do Brasil” → F  |  “7 − 1 = 5” → F

Não são proposições: “Vá tomar banho.” (ordem)  |  “Que horas são?” (pergunta)

2.2Os 5 conectivos

Conectivos juntam proposições simples para formar proposições compostas.

SímboloNomeLeituraRegra para decorar
¬pNegaçãonão pInverte: V vira F, F vira V
p ∧ qConjunçãop e qSó é V se os dois forem V
p ∨ qDisjunçãop ou qSó é F se os dois forem F
p → qCondicionalse p, então qSó é F em V → F
p ↔ qBicondicionalp se e somente se qÉ V quando os dois são iguais
Entendendo o “se… então” com uma promessa

“Se você tirar 10, então eu te dou um bolo.” A promessa só é quebrada (F) quando você tira 10 e não ganha o bolo. Se você não tirou 10, a promessa não foi quebrada, ganhando o bolo ou não.

p = “tirou 10” é o antecedente; q = “ganha bolo” é o consequente.

Entendendo o “se e somente se”

“Você será aprovado se e somente se tiver média 7.” É V quando as duas coisas acontecem juntas ou nenhuma acontece. É F quando só uma acontece (média 7 e reprovado, ou aprovado sem média 7).

2.3Tabela-verdade

A tabela-verdade mostra o resultado para todas as combinações possíveis de V e F.

pq¬pp ∧ qp ∨ qp → qp ↔ q
VVFVVVV
VFFFVFF
FVVFVVF
FFVFFVV

Número de linhas = 2n (n = quantidade de letras diferentes). 1 letra → 2 linhas, 2 letras → 4, 3 letras → 8.

Como preencher as colunas iniciais sem errar

Com 3 letras (8 linhas): a 1ª coluna tem 4 V e 4 F, a 2ª alterna de 2 em 2, a 3ª alterna de 1 em 1.

pVVVVFFFF
qVVFFVVFF
rVFVFVFVF
Exercícios rápidos (do slide)

Se V(q) = V e V(p ∧ q) = F, então V(p) = F (se p fosse V, o “e” daria V).

Se V(q) = F e V(p → q) = F, então V(p) = V (o único F do “se… então” é V → F).

Se V(q) = F e V(p ∨ q) = F, então V(p) = F.

2.4Ordem dos conectivos e montando uma tabela

Ordem (do primeiro ao último):

( ) → ¬ → ∧ e ∨ → → → ↔

Parênteses de dentro para fora, depois negação, depois “e”/“ou”, depois “se… então”, por último “se e somente se”.

Leitura correta

¬p ∨ q significa (¬p) ∨ q, e não ¬(p ∨ q).

p ∧ q → r significa (p ∧ q) → r.

Montando passo a passo: ¬(p ∨ ¬q)

Faça uma coluna para cada pedaço, do menor para o maior.

pq¬qp ∨ ¬q¬(p ∨ ¬q)
VVFVF
VFVVF
FVFFV
FFVVF

Resultado: só é V quando p = F e q = V, ou seja, é o mesmo que ¬p ∧ q.

2.5Tautologia, contradição e contingência

Olhe só para a última coluna da tabela:

Tautologia: só V. Ex.: p ∨ ¬p (ou chove ou não chove).

Contradição: só F. Ex.: p ∧ ¬p (chove e não chove).

Contingência: mistura de V e F. Ex.: p ∨ q.

p¬pp ∨ ¬pp ∧ ¬p
VFVF
FVVF
Classificações do slide

Tautologias: p → p,  (p → q) ∨ (q → p),  p → (q → p)

Contradição: p ↔ ¬p

Contingências: p ∨ q ∨ r,  (p ∧ q) ∨ (¬p ∧ q)

2.6Implicação (⇒) e equivalência (⇔ ou ≡)

p ⇒ q (p implica q) quando p → q é tautologia.

p ⇔ q ou p ≡ q (p é equivalente a q) quando p ↔ q é tautologia. Quer dizer: escrita diferente, mesmo significado.

Não confunda

A seta → é um conectivo (uma operação que pode dar V ou F). O ⇒ é uma afirmação de que essa seta dá sempre V. A tabela do → sozinha não é tautologia.

Exemplo: adição, p ⇒ p ∨ q
pqp ∨ qp → (p ∨ q)
VVVV
VFVV
FVVV
FFFV

Última coluna toda V → é tautologia → a implicação vale. Da mesma forma, simplificação: p ∧ q ⇒ p.

2.7Leis de equivalência (as “ferramentas”)

Estas são as regras usadas para simplificar expressões. Todas podem ser provadas com tabela-verdade.

LeiExpressão
Dupla negação¬¬p ≡ p
Idempotênciap ∧ p ≡ p    p ∨ p ≡ p
Comutativap ∧ q ≡ q ∧ p    p ∨ q ≡ q ∨ p
Associativap ∧ (q ∧ r) ≡ (p ∧ q) ∧ r
Distributivap ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r)
p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
Absorçãop ∧ (p ∨ q) ≡ p    p ∨ (p ∧ q) ≡ p
De Morgan¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q
Terceiro excluídop ∨ ¬p ≡ V
Contradiçãop ∧ ¬p ≡ F
Identidadep ∧ V ≡ p    p ∨ F ≡ p
Dominaçãop ∨ V ≡ V    p ∧ F ≡ F
Condicionalp → q ≡ ¬p ∨ q
Negação do condicional¬(p → q) ≡ p ∧ ¬q
Contrapositivap → q ≡ ¬q → ¬p
Bicondicionalp ↔ q ≡ (p → q) ∧ (q → p)
Pegadinha clássica

p → q não é equivalente a q → p (a recíproca). “Se chove, a rua molha” não garante “se a rua molha, choveu” (pode ter sido um caminhão-pipa).

O que é equivalente é a contrapositiva: “se a rua não molhou, não choveu”.

Regras de raciocínio (argumentos válidos)

Modus Ponens: [(p → q) ∧ p] ⇒ q. “Se chove, levo guarda-chuva. Choveu. Logo, levo.”

Modus Tollens: [(p → q) ∧ ¬q] ⇒ ¬p. “Se chove, levo guarda-chuva. Não levei. Logo, não choveu.”

Silogismo hipotético: [(p → q) ∧ (q → r)] ⇒ (p → r). A seta “passa adiante”.

Silogismo disjuntivo: [(p ∨ q) ∧ ¬p] ⇒ q. “É café ou chá. Não é café. Logo, é chá.”

2.8Simplificando expressões (álgebra proposicional)

Em vez de montar tabela, aplique as leis de 2.7 uma de cada vez, como numa conta de álgebra.

Exemplo 1: (p ∧ q) ∨ (p ∧ ¬q)
  1. Distributiva ao contrário (coloca p em evidência): p ∧ (q ∨ ¬q)
  2. Terceiro excluído, q ∨ ¬q ≡ V: p ∧ V
  3. Identidade: p
Exemplo 2: ¬(p ∨ ¬q)
  1. De Morgan (“ou” vira “e”, nega cada um): ¬p ∧ ¬¬q
  2. Dupla negação: ¬p ∧ q (bate com a tabela de 2.4)
Exemplo 3: (p → q) ∧ p
  1. Troca o condicional: (¬p ∨ q) ∧ p
  2. Distributiva: (¬p ∧ p) ∨ (q ∧ p)
  3. Contradição, ¬p ∧ p ≡ F: F ∨ (p ∧ q)
  4. Identidade: p ∧ q
Exemplo 4: ¬[p → (q ∧ r)]
  1. Negação do condicional, ¬(p → Q) ≡ p ∧ ¬Q: p ∧ ¬(q ∧ r)
  2. De Morgan: p ∧ (¬q ∨ ¬r)
Dica

Quase toda simplificação usa as mesmas quatro ferramentas: trocar o → por ¬p ∨ q, De Morgan, distributiva e depois limpar com p ∨ ¬p ≡ V ou p ∧ ¬p ≡ F.

2.9Técnicas de demonstração

Para provar uma afirmação do tipo “se hipótese, então tese” (p → q):

Prova direta: suponha p verdadeira e chegue em q.

Contraposição: prove ¬q → ¬p (vale porque é equivalente a p → q).

Redução ao absurdo: suponha p e ¬q e chegue numa contradição. Base: p → q ≡ (p ∧ ¬q) → F.

Direta: a soma de dois pares é par

Todo par pode ser escrito como 2 vezes um natural. Sejam n = 2r e m = 2s. Então n + m = 2r + 2s = 2(r + s). Como r + s é natural, n + m é par. ∎

Contraposição: se n! > n + 1, então n > 2

A contrapositiva é: se n ≤ 2, então n! ≤ n + 1. Basta testar os naturais 0, 1 e 2:

0! = 1 ≤ 1 ✔   1! = 1 ≤ 2 ✔   2! = 2 ≤ 3 ✔  Provado. ∎

Absurdo: 0 é o único elemento neutro da adição em ℕ

Suponha que existe outro neutro e ≠ 0. Como 0 é neutro: e + 0 = e. Como e é neutro: e + 0 = 0. Então e = 0, o que contradiz e ≠ 0. Absurdo, logo o neutro é único. ∎

3.1Conjuntos e lógica são a mesma coisa

Cada operação de conjuntos corresponde a um conectivo. Se você entende um lado, entende o outro.

ConjuntosLógicaPor quê
A ∪ Bp ∨ qx ∈ A ∪ B ⇔ (x ∈ A) ∨ (x ∈ B)
A ∩ Bp ∧ qx ∈ A ∩ B ⇔ (x ∈ A) ∧ (x ∈ B)
Ā (complementar)¬px ∈ Ā ⇔ ¬(x ∈ A)
A ⊂ Bp → qse x ∈ A, então x ∈ B
A = Bp ↔ qx ∈ A se e somente se x ∈ B
∅  /  UF  /  Vnunca / sempre

Repare que De Morgan aparece igualzinho nos dois: (A ∪ B)c = Ac ∩ Bc e ¬(p ∨ q) ≡ ¬p ∧ ¬q.

3.2No código (Kotlin)

O slide usa Pascal (not, and, or). Em Kotlin/Java a ideia é a mesma:

// Lógica
val p = true
val q = false
!p          // ¬p     → false
p && q      // p ∧ q  → false
p || q      // p ∨ q  → true
!p || q     // p → q  → false  (não há operador pronto de "se... então")
p == q      // p ↔ q  → false

// Conjuntos
val a = setOf(0, 2, 4, 6, 8)
val b = setOf(2, 3, 5, 7)
a union b        // A ∪ B → [0, 2, 4, 6, 8, 3, 5, 7]
a intersect b    // A ∩ B → [2]
a subtract b     // A − B → [0, 4, 6, 8]
3 in b           // 3 ∈ B → true
b.containsAll(setOf(3, 5))   // {3, 5} ⊂ B → true

Curiosidade que o slide mostra em Pascal: como false < true, a expressão p <= q também funciona como p → q.

3.3Exercícios com gabarito

Tente resolver antes de abrir a resposta.

Conjuntos

1. A = {1, 2, 3} e B = {3, 4}. Calcule A ∪ B, A ∩ B, A − B e B − A.

A ∪ B = {1, 2, 3, 4}, A ∩ B = {3}, A − B = {1, 2}, B − A = {4}

2. Quantos subconjuntos tem {a, b, c, d}?

São 4 elementos, então 2⁴ = 16 subconjuntos.

3. Verdadeiro ou falso: 2 ∈ {1, 2, 3}; {2} ∈ {1, 2, 3}; ∅ ⊂ {1}; {1, 2} = {2, 1, 1}.

V; F (o certo é {2} ⊂ {1, 2, 3}); V; V.

4. Numa turma de 40 alunos, 25 gostam de futebol, 20 de vôlei e 8 não gostam de nenhum. Quantos gostam dos dois?

Gostam de algum: 40 − 8 = 32. Pela fórmula: 32 = 25 + 20 − x, então x = 13.

Lógica

5. Com p = V e q = F, qual o valor de p ∧ q, p ∨ q, p → q, q → p, p ↔ q e ¬p ∨ q?

F, V, F, V, F, F. (Repare que ¬p ∨ q dá o mesmo que p → q.)

6. Classifique (p → q) ∨ p.

Troque o condicional: ¬p ∨ q ∨ p. Como ¬p ∨ p ≡ V, sobra V ∨ q ≡ V. É tautologia.

7. Simplifique ¬(¬p ∧ q).

De Morgan: ¬¬p ∨ ¬q. Dupla negação: p ∨ ¬q.

8. Escreva a negação de “Se chove, então levo guarda-chuva”.

Usando ¬(p → q) ≡ p ∧ ¬q: “Chove e não levo guarda-chuva”.

9. Escreva a contrapositiva de “Se estudo, então passo”.

¬q → ¬p: “Se não passei, então não estudei”.

10. Monte a tabela de p → (p ∨ q) e diga se é tautologia.

A última coluna dá V, V, V, V (veja o exemplo em 2.6). É tautologia, por isso p ⇒ p ∨ q.
