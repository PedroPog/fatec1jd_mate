# 📚 Portal de Estudos — Fatec

Portal de estudos desenvolvido com **Angular** e **Firebase**, reunindo resumos, dúvidas por seção, fórum e materiais de apoio.

🔗 **Acesse online:** [portal-apoio-geral.web.app](https://portal-apoio-geral.web.app)

## 🛠️ Tecnologias

- **Front-end:** Angular, TypeScript, HTML, CSS
- **Back-end / Hosting:** Firebase
